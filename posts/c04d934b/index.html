歡迎造訪 Siaospeed 的部落格 Aloe！

為什麼叫這個部落格 Aloe？

搜尋了很久部落格方案，從 Hugo 到 Mkdocs，最終選擇了 Hexo。

起名字的時候倒是想到了很多炫酷的詞語，比如 Rvalue, Epoch… 但是最終還是被 Aloe (蘆薈) 吸引住了。

而 Aloe 這個詞的來歷，事實上是我之前一部 Pixel 8a 蘆薈綠 的配色，但是很不幸的是它壞掉了，所以也有懷念這部手機的意味。

同時它也代表著一種清新的生命力量，就像我在複雜的 Linux 系統和網路世界裡，依然想要保持一份簡單和純粹。

Aloe 會記錄哪些內容？

Aloe 會記錄使我提起興趣的事物或配置流程

  • 折騰 Proxmox VE (PVE), OpenWrt, Arch Linux 等作業系統時的發現與思考

  • 配置與安裝某些程式時的步驟

  • 最近寫好的 程式碼、軟體

  • 某些值得討論問題的見解

關於本站

作為一名 Arch Linux 用戶，折騰是鐫刻在 DNA 裡的本能。本站採用 Hexo 驅動，搭配 Butterfly 主題，並託管於 GitHub Pages。圖床則使用了 Cloudflare R2 物件儲存空間，力求在輕量與美觀之間找到平衡。

寫在最後

蘆薈是一種不需要太多關注也能在嚴酷環境下生存的植物，這也正是我對這個部落格的期許：安靜、韌性、療癒。

學習 AI 和電腦科學的道路漫長且充滿噪聲，我希望這裡能成為我思維的緩衝區。我不承諾高頻更新，但會儘量保證內容的真實與乾貨。

Hello World, 這是 Aloe 的第一天。
