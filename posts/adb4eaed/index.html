不使用啟動磁碟給主機安裝 Windows 10 (PXE 網路開機實戰)

發表於2026-01-31|更新於2026-02-01|折騰日誌
|瀏覽量:

前一陣子筆者想要給家裡的一台主機重灌 Windows 10 系統，首先就想到了使用 USB 隨身碟製作啟動磁碟，尋找一番之無果後才發現我把所有的隨身碟都忘在了學校。最終採用了網路引導的方法成功安裝！接下來是筆者整理的安裝步驟與注意事項。

裝置、檔案、程式與先決條件

注意： 下面列出的裝置、檔案等，為筆者重灌系統時使用，僅供讀者參考。若有不一致的情形，應自行搜尋替代指令或程式。

  • Arch Linux 系統的筆電（作為伺服器端）、想要重灌系統的主機（作為用戶端）。

  • 用戶端主機板支援並啟用 PXE 網路啟動、伺服器端與用戶端連線至同一區域網路。

  • Windows 10 IoT Enterprise LTSC 2021 系統映像檔、網卡驅動程式

  • Dnsmasq、iPXE、wimboot、Samba 程式。

安裝步驟

注意： 下面的步驟，為筆者重灌系統時使用，僅供讀者參考。若有不一致的情形，應自行搜尋替代指令或程式。

確認並啟用用戶端 PXE 網路啟動

  1. 主機按一下開機鍵後，連續按鍵盤 DEL 鍵，進入 BIOS/UEFI 介面。

  2. 進入 Advanced 選單，選中 No Disk (PXE) 並進入，將 Onboard LAN Controller 設定為 Enabled、PXE Function Support 設定為 OnBoard。即啟用板載網路卡之 PXE 功能。

  3. 進入 Startup 選單，將 PXE 網路引導調整為第一順位 (#1)，伺服器端主機暫時配置完畢。

    • 進入 iPXE 介面，開始下載 boot_patched.wim。

    • 進入 Windows 藍色的安裝程式介面。

      耐心等待進度到 100% 完成。

    3. 寫入系統開機檔案 (BCDBoot) 系統檔案已經解開並釋出，但是還沒有開機引導檔案。需要手動寫入 BCD 開機檔案。

      輸入以下指令：

      • /s C:：指定引導分割區為 C 槽（Legacy 模式下，引導分割區與系統分割區通常為同一個）。

      • /f BIOS：強制使用 Legacy BIOS 引導格式（避免使用 UEFI 格式）

    4. 收尾並重新啟動

      1. 拔出網線防止再次從 PXE 啟動。

      2. 在命令提示字元執行 wpeutil reboot，重新啟動主機。

      3. 可能會重新啟動電腦數次，再次開機會從硬碟啟動，開始設定區域、語言、鍵盤等。

附錄：BIOS 與 UEFI 之區別與調整

隨著硬體更新，現代電腦主機板大多採用 UEFI 啟動模式，而非本教學中使用的 Legacy BIOS。若讀者的設備較新（約 2012 年後出廠），請務必參考以下差異進行調整，否則將無法順利啟動安裝程式。

  1. 核心差異對照表

    項目 Legacy BIOS（舊款） UEFI（現代）
    硬碟分割表 MBR GPT
    開機引導檔案 undionly.kpxe 或 ipxe.pxe ipxe.efi
    BCD 引導路徑 /boot/bcd /efi/microsoft/boot/bcd
    獨立引導分割區 不需要 (通常與 C 槽共用) 需要 (ESP 分割區, FAT32 格式)
    BCDBoot 參數 /f BIOS /f UEFI

  2. 伺服器端配置調整 (boot.ipxe)

    在 UEFI 模式下，Windows Boot Manager 需要讀取不同的 BCD 路徑，且強烈建議載入字型檔以免選單顯示亂碼。請修改 /srv/tftp/boot.ipxe：

  3. 用戶端 Diskpart 分割指令調整

    UEFI 系統必須使用 GPT 分割表，並且需要一個獨立的 ESP (EFI System Partition) 分割區來存放開機檔案。

寫在最後

Legacy 是為了與過去相容的一種妥協，而 UEFI 才是現代硬體的歸宿。

在 PXE 指令碼中，這僅僅體現為一列 BCD 路徑的差異，但是在作業系統的底層，卻是從真實模式到保護模式、從 BIOS 中斷到 EFI 驅動的巨大跨越。
