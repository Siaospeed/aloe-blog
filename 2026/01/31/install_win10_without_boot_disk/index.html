不使用啟動磁碟給主機安裝 Windows 10

發表於2026-01-31|更新於2026-01-31
|瀏覽量:

前一陣子筆者想要給家裡的一台主機重灌 Windows 10 系統，首先就想到了使用 USB 隨身碟製作啟動磁碟，尋找一番之無果後才發現我把所有的隨身碟都忘在了學校。最終採用了網路引導的方法成功安裝！接下來是筆者整理的安裝步驟與注意事項。

裝置、檔案、程式與先決條件

注意： 下面列出的裝置、檔案等，為筆者重灌系統時使用，僅供讀者參考。若有不一致的情形，應自行搜尋替代指令或程式。

  • Arch Linux 系統的筆電（作為伺服器端）、想要重灌系統的主機（作為用戶端）

  • 用戶端主機板支援並啟用 PXE 網路啟動、伺服器端與用戶端連線至同一區域網路

  • Windows 10 IoT Enterprise LTSC 2021 系統映像檔、網卡驅動程式

  • Dnsmasq、iPXE、wimboot、Samba 程式

安裝步驟

注意： 下面的步驟，為筆者重灌系統時使用，僅供讀者參考。若有不一致的情形，應自行搜尋替代指令或程式。

確認並啟用用戶端 PXE 網路啟動

  1. 主機按一下開機鍵後，連續按鍵盤 DEL 鍵，進入 BIOS/UEFI 介面

  2. 進入 Advanced 選單，選中 No Disk (PXE) 並進入，將 Onboard LAN Controller 設定為 Enabled、PXE Function Support 設定為 OnBoard。即啟用板載網路卡之 PXE 功能

  3. 進入 Startup 選單，將 PXE 網路引導調整為第一順位 (#1)，伺服器端主機暫時配置完畢。
